# ShipSync Hub

Gateway de logística e fretes — Laravel 11, Clean Architecture, Redis, Memcached, LocalStack (SQS, S3, DynamoDB), Pest (TDD).

## Início rápido

```bash
docker compose up -d
cp .env.example .env   # se ainda não existir
./bin/composer install
./bin/test
```
